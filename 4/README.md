Защита:
range — это конечная последовательность. У неё есть начало, конец и шаг, поэтому число итераций известно заранее
Шаг только +1. При a > b (например, 4, 2) range(4, 2) пуст, а надо убывание 4, 3, 2. Нужен шаг -1
range(a, b) Не различает три случая. Задание требует три режима: возрастание (a < b), убывание (a > b), одно число (a == b)

Отличие / от //:
/ — обычное деление, результат float. 7 / 2 = 3.5, 4 / 2 = 2.0.
// — деление с округлением вниз до целого. 7 // 2 = 3, -7 // 2 = -4.

Смысл остатка %:
a % b — то, что осталось после выделения максимального числа целых b из a

float хранит дроби неточно. Например, 0.1 + 0.2 даёт 0.30000000000000004, а не 0.3. Формат :.2f просто обрезает вывод до двух знаков, но само число внутри программы остаётся неточным.
